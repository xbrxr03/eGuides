7 Skills · 1 Agent

The Claude Code Design Agent Stack

Seven free skills that stack into one pipeline: reverse-engineer any UI's design language, build it back out in 3D and motion, then render the whole thing as a finished video — all from inside Claude Code.

Install Pattern

Same two commands, every time.

/plugin marketplace add <owner>/<repo>
/plugin install <skill>@<repo>

Restart Claude Code and the skill is live. Swap in each repo below — the exact skill name for the second command is in that repo's README.

npx skills add <owner>/<repo> -g

Not on Claude Code? This one command covers Codex, Cursor, Copilot, Gemini CLI, and 50+ other hosts.

Starter prompt — adapt to your own voiceover

Build me a motion-graphic video using only free tools — no Premiere, no After Effects, no CapCut.

1. Clone github.com/halicotampa-crypto/motion-pack for the HTML templates
   and Whisper transcribe/silence-cut scripts.
2. Transcribe my voiceover MP3 and match a template to every spoken phrase.
3. Render each matched template with HyperFrames
   (github.com/heygen-com/hyperframes).
4. Stitch the rendered clips into the final video with Remotion
   (github.com/remotion-dev/remotion).
